TriTD: Tri-Partite Trajectory-Distribution Distillation for Real-Time Autoregressive Video Generation

TriTD：面向实时自回归视频生成的“轨迹-分布”三部分联合蒸馏

🏛 香港大学、字节跳动 Seed、清华大学📅 提交于 2026-10-19arXiv:2610.26165
蒸馏DMD自回归视频实时生成
问题

自回归（AR）视频扩散按块（chunk）生成、用 KV Cache 承接历史，但 Self-Forcing 一类蒸馏方案存在两处“训练-推理不一致”：训练时每块的退出时间步随机采样，推理时却总走完整链；而且每块去噪后还要额外跑一次前向（t=0）来刷新干净的 KV Cache，4 步生成实际要 5 次 NFE。

方法

作者先给出单块误差上界 ec ≤ ε + κ·|σinf(c) − σtr(c)| + L·ec−1，把误差拆成基座误差 ε、训练-推理噪声失配、上游误差传播三项，并推出累积误差中越靠前的块权重越大。三个模块分别针对前两项和 DMD 本身的不稳定：

  1. Next-Node Trajectory Distillation（NTD）ODE 初始化阶段不再让学生直接回归教师轨迹终点 x₀（L2），而是回归教师 ODE 轨迹上的下一个节点 xti+1，并改用对离群点更鲁棒的 L1。论文证明（Lemma 2）其回归误差下界严格更低，从而压低 ε。
  2. Chunk-Graded Noising（CGN）两条约束：Clean Start（第一块训练时噪声恒为 0，与推理一致）和 Sorted Noise（后续各块的起始/退出时间步单调不减，模拟推理时误差沿块累积）。模型因此学会直接用“带噪”的上下文，推理时可彻底跳过每块结束后的 KV Cache 重算，4 步即 4 NFE。
  3. Orthogonal-Parallel DMD（OP-DMD）标准 DMD 只沿梯度方向 r = x̂real − x̂fake 提供监督，正交子空间无约束，会产生“离轴漂移”与训练震荡。OP-DMD 把学生与教师预测之差 δ 分解为平行分量和正交分量，额外加 L1 惩罚：L = LDMD + λ⊥R(δ⊥) + λ∥R(α)，λ∥=1e-4 ≪ λ⊥=0.01。
设置
需要训练（ODE 初始化 + DMD 蒸馏两阶段，CGN 贯穿始终）。基座 Wan2.1-1.3B（832×480，5 秒），先按 CausVid 做块因果微调；学生每块 3 帧、4 步去噪。
结果
VBench（MovieGen 前 128 条提示）质量分 83.59，为所有对比方法最高；单张 H100 吞吐 26.8 FPS（torch.compile）/ 22.2 FPS（不编译），FPS 只统计扩散主干、不含 VAE 解码。仅用 4 NFE 即超过 5 NFE 的 Self-Forcing（+1.26）和 Causal-Forcing（+0.68）。
为什么值得看

字节 Seed 出品，对 Self-Forcing / DMD 这一路自回归蒸馏做了有理论支撑、可逐项消融的系统改进；CGN“去掉额外前向”的技巧几乎零成本，值得直接借鉴。

RECAP: Reciprocal Sparse Attention and Hierarchical Caching for Efficient Video Diffusion

RECAP：稀疏注意力与分层缓存“互惠校正”的高效视频扩散

🏛 上海交通大学、剑桥大学（通讯作者 张宇伦）📅 提交于 2026-10-19arXiv:2610.26244
稀疏注意力特征缓存免训练
问题

稀疏注意力（省单步内计算）和时间步缓存（省跨步计算）天然可以叠加，但叠加后稀疏预测会成为后续缓存复用的“源”，稀疏误差会被复用多步。作者实验发现：把缓存源换成稠密结果能明显降低偏差；而且相邻步的稀疏化误差方向高度一致——一次稠密校正可以服务多次稀疏计算。

方法

据此构建两级缓存，每步在三种动作中选一：直接外推复用预测、做“带校正的稀疏计算”、或做一次稠密刷新（dense refresh）。

  1. 注意力级缓存：粗尾估计 + 缓存稠密残差把每个 query 的 key 分成精确计算的选中块 H 和省略的尾部 T。尾部先用块均值加二阶矩修正得到粗估计（log-mass 与输出）；稠密刷新时算出真实尾部与粗估计之差 dh 并缓存，之后的稀疏步用“新鲜粗估计 + 旧残差”重建，误差只取决于残差本身的变化。
  2. 漂移加权（Drift-weighted refinement）随着复用步数增加，旧残差会过时。用当前粗统计相对刷新时的偏移（按 query 行去中心化）计算权重 at，自动减弱过时残差的作用，无需额外超参。
  3. 预测级缓存：增益拟合外推用最近两次计算的预测估计变化率，p̂t = ps + αs(t−s)vs，增益 α 用在线累积最小二乘拟合；被校正过的稀疏预测会更新这一历史，使一次稠密刷新可以支撑多次稀疏计算和其后的复用。
  4. 误差反馈的在线调度预测误差决定“何时算”（在固定预算 B 内自适应拉长或缩短复用间隔），稠密刷新时的校验误差决定“是否需要稠密算”，无需离线搜索调度表。
设置
免训练，配合 FlashAttention-2、Block-Sparse Attention 与自定义 Triton 内核。评测 CogVideoX-1.5-5B、HunyuanVideo-13B、Wan2.1-1.3B（均 50 步），附录扩展到 FLUX.1-dev。
结果
HunyuanVideo 720p、5 秒生成上 3.05× 加速，保真度和速度均优于所有测试的“稀疏 + 缓存”直接组合（SVOO/DFSAttn × TeaCache/LeMiCa/NaviCache）。常规加速区间：RECAP-Quality 相对最强单一基线 PSNR +3.74 dB（CogVideoX-1.5）/ +1.42 dB（HunyuanVideo）；RECAP-Speed 加速 1.75× / 2.14×。
为什么值得看

“稀疏 × 缓存”如何正确组合是工程落地的真问题；本文给出的是有实验动机、可即插即用的方案，代码已开源。

SpecKCast: Spectral Kalman Forecasting for Diffusion Acceleration

SpecKCast：基于频谱卡尔曼预测的扩散加速

🏛 多伦多大学、Vector Institute、三星多伦多 AI 中心📅 提交于 2026-10-19arXiv:2610.26837
特征预测/缓存免训练DiT 加速
问题

TaylorSeer、Spectrum 等“特征预测（forecasting）”方法把输出当作一个整体、用统一规则外推，并以步序号作时间轴。但作者观察到：低频成分在前几步剧烈变化后趋稳，高频成分则在后期才快速演化；且每步实际去噪量并不均匀——跳得越多误差越大。

方法

直接预测采样器消费的最终速度输出（而非中间特征），在频域对每个系数单独建模，并用不确定性决定何时真正调用 Transformer：

  1. 空间频率分解对输出 Yj 逐通道做正交 2D DCT，按半径把频率平面分为 L=7 个频带；每个 DCT 系数是一个独立的时间信号，跳过的步上预测出 Ẑj 后再做 IDCT 交给采样器。
  2. 分频带的去噪时间坐标时间轴不用步序号，而用噪声调度的对数信噪比 λj，并按各频带校准的信号功率做非线性扭曲、再缩放到 [−1,1]，使坐标在该频带“活跃”时走得快、稳定时走得慢。
  3. 卡尔曼滤波跟踪每个系数状态为（值 m，导数 ν），按 mj = mj−1 + Δ·νj−1 推进，导数以 e−Δ/τ 衰减以防长跳时过冲；计算步做卡尔曼更新，同频带共享协方差，只需维护 L 个 2×2 矩阵。
  4. 不确定性驱动调度把各频带预测方差按系数数加权汇成标量风险 R(k)，一旦超过阈值 ε 就执行一次完整前向；ε 按目标算力预算标定。
设置
免训练、即插即用，额外显存 <0.05 GiB。评测 FLUX.1-dev、Qwen-Image 与视频模型 Wan2.1-14B、HunyuanVideo，以 50 步为参考，H100 上测试。
结果
HunyuanVideo 14-NFE 预算下比最强基线 SeaCache PSNR 高 2.1 dB，速度 3.33×（SeaCache 2.57×）；Wan2.1-14B 各预算下 VBench Quality 均为最佳，14-NFE 时与原模型差距在 0.25 分以内。图像上最高 5.54×（FLUX）/ 6.00×（Qwen-Image），分别比最强基线高 1.1 / 2.0 dB。
为什么值得看

把“特征外推”升级为频域 + 不确定性驱动的自适应计算，思路优雅、开销极小，对任何 DiT 视频模型都可直接尝试。

Dynamics-Aware Sparse Attention for Efficient Autoregressive Video Diffusion

DASA：面向高效自回归视频扩散的动态感知稀疏注意力

🏛 浙江大学、阿里巴巴、莫纳什大学📅 提交于 2026-10-19arXiv:2610.26262
稀疏计算KV 缓存压缩自回归视频蒸馏
问题

自回归视频 DiT 对所有时空区域平均分配算力和显存：滑动窗口会丢掉旧场景（回头时不一致），而背景等静态区域每块都在被重复去噪。现有加速如 TeaCache 在 4 步模型上空间有限（仅 1.18×）。

方法

借鉴 H.264 的 I 帧 / P 帧思想，把视频显式拆成动态区域和静态区域，从“存什么”和“算什么”两个正交维度去冗余：

  1. 逐帧记忆管理（Frame-wise Memory Management）上一块最后一帧作为参考帧完整保留；其余 token 与相邻帧余弦相似度高于阈值 σl 的不写入 KV Cache。σl 随层深线性下降（深层语义稳定，保留更少）。再加静态 token 刷新：某位置连续被丢超过 τ 帧（取 τ=4）就强制写入，防止背景细节和光照变化“陈旧化”。
  2. 区域级计算分配（Motion-aware early exit）当前块第一步去噪得到的 X̂C 与上一块在 w×w 局部窗口内做匹配（能跟踪运动物体，复杂度对序列长度线性）；最大相似度超过 γ（取 0.92）的 token 直接早退，复制上一块的对齐 token，只有动态 token 继续后续去噪。
  3. 动态引导蒸馏（Dynamics-Guided Distillation）把上述机制放进训练后，模型会“偷懒”倾向于复制历史、动作变僵（static bias）。作者在 DMD 损失上按真实视频的时间相似度构造逐 token 权重，运动越大的区域损失放大越多，迫使模型学会生成真实动态。
设置
推理机制可直接使用，另有轻量蒸馏微调。集成到 Self-Forcing 与 LongLive，覆盖 5 秒、30 秒长视频以及 720P/1080P 高分辨率生成，H100 测试。
结果
5 秒视频 1.53×（TeaCache 仅 1.18×）；30 秒长视频最高 1.45×；加速随分辨率增大，1080P 下最高 2.16×。加入动态引导蒸馏后吞吐达 27.58 FPS（1.50×）且语义分最高。已被 NeurIPS 2026 接收。
为什么值得看

同时针对长视频自回归的算力与显存两大瓶颈，“只算会动的地方”直觉清晰，且与 TeaCache 等缓存方法正交可叠加。

Clean Forcing: Drift-Resistant Autoregressive Video Diffusion with a Frozen Base

Clean Forcing：冻结基座下抗漂移的自回归视频扩散

🏛 首尔国立大学、美国东北大学、NVIDIA📅 提交于 2026-10-19arXiv:2610.25634
长视频LoRA 后训练曝光偏差
问题

自回归视频在干净历史上训练、却以自己生成的有误差历史为条件推理（曝光偏差，exposure bias），几秒后就会漂移到过饱和、无纹理。现有方案要么重训基座（最强结果用 13.6 万段视频、16×H100），要么是推理时启发式修正、在 50 秒尺度上并不可靠。

方法

关键发现：在同一个带噪状态 zt 下只替换历史（干净 vs 漂移），得到的速度差 Δv = vθ(zt, hclean) − vθ(zt, hgen) 在不同噪声种子间约 95% 是系统性的（三个基座上 0.89–0.99）——漂移是确定性的，因此可学。

  1. 反事实教师校正冻结基座，只训练 rank-16 LoRA（自注意力投影上，5.9M 参数，约基座 0.4%）：学生在漂移历史下的速度去拟合冻结教师在干净历史下的速度，损失按原始漂移幅度归一化；LoRA B 矩阵零初始化，起点与基座完全一致。
  2. 闭环训练：DAgger 聚合开启校正器后重新生成训练对并加入数据池，让校正器见到自己 rollout 时真正会遇到的状态，缓解协变量偏移。
  3. 漂移收缩（Drift contraction）由校正后的速度估计 x̂₀ 并保留梯度接入历史，在下一块上计算归一化速度差（λcon=0.5），直接惩罚“这一步提交的预测对下一块造成的漂移”。
  4. 自教学，无需真实视频干净历史可以由同一模型在双向单次生成模式下自己产生，所以只需提示词；也可用少量真实片段（40 段就够）。
设置
需要训练（约 1 个 GPU 日），LoRA 可合并进权重，推理零额外开销。主实验基座为轻度因果化的 Wan2.1-1.3B，并验证 Causal-Forcing 基座及 10 倍大的 Wan2.1-T2V-14B。
结果
50 秒文生视频（128 条 MovieGen 提示）Δ-drift 从 +11.3 降到 +1.65（无真实视频）、−0.16（40 段真实视频），优于已发表最佳 +3.57，数据量少 150 倍以上；14B 基座上消除 94% 漂移。用户研究中 +real 版本相对基座胜率 93.0%、相对 Self Forcing 83.9%。
为什么值得看

极低成本的长视频后训练：不动基座、几乎不要数据、不增加推理成本，性价比极高，可直接套用到已发布的 AR 视频模型。

PoSTCache: From Forecasting to Postdictive Smoothing for Revisable Diffusion Caching

PoSTCache：从前向预测到“事后平滑”的可修正扩散缓存

🏛 清华大学（丁贵广、韩军功团队）📅 提交于 2026-10-19arXiv:2610.25664
特征缓存免训练即插即用
问题

现有缓存加速都是“只向前”的：被跳过步的近似一旦写入采样轨迹就不再修改，误差沿后续步累积；而后面的完整计算步其实揭示了关于这些误差的新信息，却只被用来指导之后的采样。

方法

受贝叶斯平滑（RTS smoother）启发，把缓存重新表述为可修正的轨迹推断：平滑估计 = 前向估计 + 平滑增益 × 未来新息（innovation）。

  1. 事后平滑（Postdictive smoothing）在两个完整计算锚点 a<b 之间，先用任意已有缓存策略（默认直接复用）给出前向提议；到 b 时用真实预测与其提议之差 rb 作为新息，按 ûk = ũk + wk·rb 反向修正中间各步，增益 w 随相对位置从 0 线性增至 1。实验显示这种简单增益保留了 oracle 标量增益 96–97% 的可解释误差。
  2. 轨迹重积分只修正预测还不够，再用原采样器从锚点 a 起把修正后的预测重新积分一遍；只涉及廉价的求解器运算，不增加网络前向。
  3. 后验方差缩减锚点选择（PVR）作者发现“局部误差最大的步”并不是最有校正价值的锚点（两者 Spearman 相关为负）。于是离线采集完整轨迹估计跨时间步协方差核 K，在给定预算下贪心选择使加权轨迹后验方差下降最多的锚点。
设置
免训练、即插即用，可叠加在 MagCache、DiCache 等缓存方法之上。评测 FLUX.1-dev、Qwen-Image-2512，视频模型 Wan 2.1-1.3B、CogVideoX-2B、OpenSora 1.2。
结果
在可比或更高加速比下持续提升重建保真度（PSNR/SSIM/LPIPS），并保持有竞争力的 VBench 质量；论文正文未给出单一的视频加速倍数总结，故此处不列具体数字。消融显示平滑与 PVR 各自有效、组合最佳。
为什么值得看

视角新颖——从“预测未来”转到“用未来修正过去”，作为通用后处理可叠加在任意缓存方法上，与 SpecKCast 对照阅读很有启发。

Fréchet Forcing: Training Long-Horizon Streaming World Models from Short Clips

Fréchet Forcing：只用短片段训练长时程流式世界模型

🏛 论文首页未标注机构📅 提交于 2026-10-19arXiv:2610.25666
长视频世界模型无教师后训练
问题

动作条件的流式世界模型只在短片段上训练，rollout 超出训练长度就会漂移。常用的 DMD 自 rollout 训练依赖教师：外部视频模型不懂动作，而模型自己的预训练网络又和学生一样会漂移。

方法

长 rollout 不必对齐某个教师，只要满足三点：仍是遵循动作的条件生成器、忠于自己的场景、画面真实。三者分别用一个约束实现（权重均为 1）：

  1. 生成锚定（Generative anchoring）从真实片段取前 c 块，加噪到 t=0.7 后用部署采样器自回归重绘（带入模型自身误差），再在其后 4 个真实块上施加 flow-matching 损失。关键细节：历史最后一块必须换回真实数据，否则模型会学成在块边界“重画场景”，产生块级闪烁。
  2. 上下文保真（Context fidelity）让模型用部署采样器自由 rollout，对潜变量的逐通道均值/标准差（相邻两帧拼接以捕捉时间变化）减去该片段自身真值均值，再与真实视频计算 Fréchet 距离——把“群体统计”变为“逐片段条件”，防止塌缩到数据集平均外观。
  3. 真实性匹配（Reality matching）把最后若干块解码到像素，用冻结的 DINOv2 ViT-B/14 CLS 特征与真实帧（经同一 VAE 重建）计算 Fréchet 距离，排除变暗、发白、周期平铺等退化解。
  4. 工程细节Fréchet 距离的一、二阶矩用 EMA 维护以扩大有效样本；损失写成 FD / sg(FD)，梯度等价于 ∇log FD，各项量纲自动对齐；只对最后 K 步保留梯度，历史以 detach 方式进入 KV Cache。
设置
需要微调，但不需要教师、在线判别器或长视频。基座 MiniWorld-1B（在 253 帧片段上预训练），在 381 帧片段上微调，最多 36 GPU 小时；任务覆盖 DROID 机器人操作与 Sekai 相机控制探索。
结果
微调后 rollout 在 4,000 帧以上保持稳定并持续遵循动作；DROID 上相对正反向回放的 PSNR 到第 4,000 帧仍 >21 dB，基座仅 8.9 dB。
为什么值得看

为 Self-Forcing 类长视频后训练提供了不依赖教师的新范式，训练成本低，对世界模型、交互式视频生成方向尤其有参考价值。

FluidGen: Physics-Aware Fluid Video Generation via Motion-Guided Post-Training

FluidGen：基于运动引导后训练的物理感知流体视频生成

🏛 斯坦福大学（Jiajun Wu、Gordon Wetzstein、Leonidas Guibas 团队）📅 提交于 2026-10-19arXiv:2610.25660
后训练DPO 偏好对齐物理一致性
问题

视频生成模型在烟、火、爆炸碎片等流体现象上系统性失败：缺乏连贯的涡旋结构、动态塌缩得平淡；传统求解器虽物理准确，却需要完整 3D 场景和精调参数，无法用于任意图像输入。

方法

把数据驱动的流体先验直接“烤进”视频模型：让模型同时生成 RGB 与逐像素 3D 速度场，再把速度场作为可解释的物理信号做偏好对齐。

  1. 速度场编码每像素速度 v=(vx,vy,vz) 经球坐标分解编码成 3 通道“颜色”，从而可以直接复用原 VAE 编解码，不必另训潜空间。
  2. 双头 DiT在 Wan 14B 图生视频 DiT 上把 patch embedding 输入从 16+K 扩到 16+16+K 通道、输出头从 16 扩到 32 通道，新增部分零初始化，起点即原模型；RGB 与速度共享同一去噪器、沿同一轨迹采样，保证两者因果一致。
  3. 阶段一：联合监督微调在 Houdini 仿真（烟/火/爆炸 + 真值欧拉速度场）与真实流体视频混合数据上做联合 flow-matching；对无速度标注的真实视频按通道掩码只监督 RGB。
  4. 阶段二：速度感知 DPO由 13 个分量组成的物理奖励（方向多样性、时间连贯、涡量/Q 准则、Kolmogorov 惯性区等，多数直接由预测速度场计算）为每个输入的 4 个样本打分，取最高/最低构成偏好对，按 Flow-DPO 目标用 LoRA 训练，参考模型即关闭 LoRA 的自身。
设置
需要训练（SFT + DPO 两阶段）。基座 Wan2.1-I2V-14B。
结果
阶段一相对基座：PSNR 22.50 → 31.52，FVD 569.7 → 192.1，VBench 主体一致性 0.8929 → 0.9383。DPO 后 FluidNexus 指标与仅微调持平，成像质量显著提升、美学略升，主体一致性小幅下降（0.9383 → 0.9350），作者解释为奖励偏好更强湍流。
为什么值得看

“辅助物理信号 → 奖励 → DPO”是视频偏好对齐的好范例：奖励直接来自模型自身输出，无需外部光流或仿真器；生成的速度场还能导回 Houdini 使用。
